\uppgiftsdel{Part 1}{Review exercises}

\uppgift{1.1}{Recovering a function of time from its derivative}
A sensor voltage $u(t)$ in a measuring circuit is not known directly, but its derivative has been
measured as
\[
  u'(t) = (6t - 4)\,\text{V/s}.
\]
The initial voltage is also known to be $u(0) = 2\,\text{V}$.
\begin{parts}
  \item Find an expression for $u(t)$.
  \item Find the voltage after $3$ seconds.
  \item Calculate the definite integral $\int_0^3 u'(t)\,dt$. Compare the value with $u(3)$ from
    b) and explain any difference.
  \item Find the time at which the voltage is stationary, i.e.\ when $u'(t) = 0$.
  \item Use the \textbf{second derivative} to decide whether the stationary point is a
    \textbf{maximum} or a \textbf{minimum}.
  \item Find the coordinates of the stationary point, i.e.\ the time $t$ and the voltage $u(t)$
    at the point.
  \item Plot the graph of $u(t)$ in GeoGebra, \url{https://www.geogebra.org/graphing?lang=en}, and
    check that your answers are right.
\end{parts}

\uppgift{2.1}{Rectangular $\rightarrow$ polar form}
Convert the voltage $U = 5 - j2\,\text{V}$ to polar form.

\uppgift{2.2}{Polar $\rightarrow$ rectangular form}
Convert the current $I = 5\angle\frac{\pi}{6}\,\text{mA}$ to rectangular form.

\uppgift{2.3}{Calculating an impedance}
A circuit is supplied with the voltage from \uppref{2.1}, and the current from \uppref{2.2} flows
through the circuit. Calculate the circuit's impedance $Z$ with “Ohm's law”:
\[
  Z = \frac{U}{I},
\]
where
\begin{itemize}
  \item $Z$ is the circuit's impedance in $\Omega$,
  \item $U$ is the supply voltage in V,
  \item $I$ is the current through the circuit in mA.
\end{itemize}
Give the answer in both polar and rectangular form.

\uppgift{3.13}{Ohm's law with complex numbers}

\uppgift{3.15}{Series and parallel impedance}
Two impedances $Z_1 = 4 + j3\,\Omega$ and $Z_2 = 4 - j3\,\Omega$ are given.
\begin{parts}

  \item Calculate $\abs{Z_1}$ and $\abs{Z_2}$.
  \item Calculate the product $Z_1Z_2$.
  \item Calculate the parallel connection $\dfrac{Z_1Z_2}{Z_1 + Z_2}$.
\end{parts}

\uppgift{3.16}{True or false}
Decide whether each statement is true or false, and justify your answer briefly.
\begin{parts}
  \item $j^2 = 1$
  \item The magnitude $\abs{z}$ can be negative.
  \item A purely imaginary number has the phase angle $90^{\circ}$ or $-90^{\circ}$.
  \item The product $(a + jb)(a - jb)$ is always real.
  \item The calculator's $\arctan$ always gives the right phase angle directly.
  \item Adding complex numbers is easiest in polar form.
\end{parts}

\uppgiftsdel{Part 4}{Mathematics in C}
The teacher shows the exercise below during the lesson if time allows, in VS Code and with
\code{make}. You can
also do it yourself in \textbf{OnlineGDB}, \url{https://www.onlinegdb.com/online_c_compiler}, with
the language set to \textbf{C}.

\needspace{16\baselineskip}
In the exercise below, a complex number is written as a \textbf{struct} of its own. A struct gathers
several variables that belong together under one name, here the real part and the imaginary part.
The type \code{complex_t} is defined with \code{typedef struct} and has the fields \code{re} and
\code{im}, both of type \code{double}:
\begin{ccode}
/**
 * @brief Complex number structure.
 */
typedef struct
{
    /** Real part (3 in z = 3 + j4). */
    double re;

    /** Imaginary part (4 in z = 3 + j4). */
    double im;
} complex_t;
\end{ccode}
\begin{itemize}
  \item \code{typedef} gives the struct the alias \code{complex_t}, so that we do not have to write
    \code{struct} every time we use it. The suffix \code{_t} shows that the name is an alias, just
    as in \code{uint8_t} from \file{stdint.h}.
  \item The number $3 + j4$ is created with \code{const complex_t z = \{3.0, 4.0\};}, or more
    clearly with \code{const complex_t z = \{.re = 3.0, .im = 4.0\};}. The fields are reached with a
    dot: \code{z.re} and \code{z.im}.
  \item Structs are passed to functions through a \textbf{pointer} (\code{complex_t*}), that is, the
    memory address of the struct, so that the whole struct does not have to be copied on every call.
    The main reason is efficiency. Here it hardly matters, since two \code{double}s take $2 \cdot
    64$ bits while a pointer takes $64$ bits, but for larger structs the difference becomes
    significant.
  \item The parameter type \code{const complex_t*} says that the function does not change the
    number.
  \item In the call, the address is given with \code{&}, for example \code{complex_magnitude(&z)}.
    Inside the function, the fields are reached with an arrow: \code{z->re} and \code{z->im}.
  \item A \code{complex_t} can, however, be returned directly, as in \code{complex_from_polar()}. A
    new number has to be created anyway, so it is simpler to do that inside the function than to
    have the caller create a variable and pass its address.
\end{itemize}

The functions \code{sqrt()}, \code{sin()}, \code{cos()}, \code{atan()} and \code{atan2()} and the
constant \code{M_PI} for $\pi$ are in \file{math.h}. The trigonometric functions work in radians.

\uppgift{4.1}{Polar form in C}
The numbers $z_1 = 3 + j4$ and $z_2 = -2 - j3$ from \secref{c15:sec:typexempel} and
$z_3 = 10\,\angle\,45^{\circ}$ are given.
\begin{parts}
  \item Give $z_1$ and $z_2$ in polar form, with the argument in degrees, and $z_3$ in rectangular
    form. Calculate by hand.
  \item Define \code{complex_t} and write the functions \code{double complex_magnitude(const
    complex_t* z)}, which returns the modulus $\abs{z}$, \code{double complex_angle_deg(const
    complex_t* z)}, which returns the argument in degrees, computed with \code{atan2(z->im, z->re)},
    \code{complex_t complex_from_polar(double r, double deg)}, which returns the number
    $r\,\angle\,\theta$ in rectangular form, and \code{void complex_print(const complex_t* z)},
    which prints the number in both rectangular and polar form, with the argument in degrees. Write
    $z_3$ as \code{complex_from_polar(10.0, 45.0)} and call \code{complex_print()} once per number.
  \item Also compute \code{atan(z2.im / z2.re)} for $z_2$ and convert the answer to degrees. Why is
    it wrong, and why does \code{atan2()} give the right quadrant?
\end{parts}
