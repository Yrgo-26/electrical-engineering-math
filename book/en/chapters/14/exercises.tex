\uppgift{1.1}{Discharging a capacitor}
The voltage across a discharging capacitor is given by the function
\[
  u(t) = 24e^{-0.25t},
\]
where $u(t)$ is the voltage across the capacitor in V and $t$ the time in seconds. The definition
of the derivative is
\[
  u'(t) = \lim_{h \to 0} \frac{u(t + h) - u(t)}{h}.
\]
\begin{parts}
  \item Find the derivative $u'(t)$ using the definition of the derivative.
  \item Calculate the rate of change of the voltage at $t = 4\,\text{s}$.
  \item Find $u''(4)$. Is the rate of change increasing or decreasing at this point, and what does
    that mean for the discharge?
\end{parts}

\uppgiftsdel{Part 2}{New material}

\uppgift{2.1}{Energy stored in an inductor}
The current through an inductor depends on time and is given by the function
\[
  i(t) = 5t,
\]
where $t$ is the time in seconds. The current is measured in amperes (A). The inductance of the
inductor is $L = 0.20\,\text{H}$ (henry).

The power $p(t)$ developed in the inductor is given by the function
\[
  p(t) = L \cdot i(t) \cdot i'(t),
\]
where
\begin{itemize}
  \item $p(t)$ is the power developed in watts (W),
  \item $L$ is the inductance of the inductor in henries (H),
  \item $i(t)$ is the current through the inductor in amperes (A),
  \item $i'(t)$ is the rate of change of the current through the inductor in A/s.
\end{itemize}
The energy $w(t)$ stored in the inductor between time $0$ and time $t$ is given by the function
\[
  w(t) = \int_0^t p(t)\,dt
\]
and is measured in joules (J).
\begin{parts}
  \item Find $p(t)$.
  \item Find the antiderivative $P(t)$ of $p(t)$.
  \item Find an expression for the energy $w(t)$ in the inductor as a function of time.
  \item The inductor is uncharged at the start, that is, $w(0) = 0$. Find the constant of
    integration $C$.
  \item Find how much energy has been stored in the inductor during the first $3$ seconds
    (${0 \leq t \leq 3}$).
\end{parts}

\uppgift{4.1}{The integral as a sum in C}
The definite integral is the area under the curve, and it can be approximated by a sum of $n$
narrow rectangles. With the width $\Delta x = \dfrac{b - a}{n}$ and the height taken at the left
edge of each rectangle,
\[
  \int_a^b f(x)\,dx \approx \sum_{k=0}^{n-1} f(a + k\,\Delta x) \cdot \Delta x.
\]
\begin{parts}
  \item Evaluate $\displaystyle\int_0^{\pi} \sin(x)\,dx$ with an antiderivative.
  \item Define the type \code{math_func_t} as in Chapter~13, \uppref[13]{4.1}, with
    \code{typedef double (*math_func_t)(double);}. Write the function
    \code{double integrate(math_func_t f, double a, double b, size_t n)}, which returns the sum
    above. The type \code{size_t} is in \file{stddef.h}. Then call
    \code{integrate(sin, 0.0, M_PI, n)} for $f(x) = \sin(x)$ on the interval $[0, \pi]$ with
    $n = 4$, $10$, $100$ and $1000$ rectangles, and print $n$, the sum and the error compared with
    the answer to a). The error is the distance between the sum and the expected answer $2.0$ from
    a). If the sum is stored in the variable \code{area}, the error is computed with
    \code{fabs(area - 2.0)}, where \code{fabs()} gives the absolute value, so the error is never
    negative. Use \code{sin()}, \code{fabs()} and the constant \code{M_PI} from \file{math.h}.
  \item How does the error change when $n$ is multiplied by ten?
  \item Evaluate $\displaystyle\int_0^{1} e^{2x}\,dx$ with an antiderivative. Then write the
    function \code{double e_2x(double x)}, which returns $e^{2x}$ using
    \code{pow(M_E, 2.0 * x)}, and call \code{integrate(e_2x, 0.0, 1.0, n)} with the same values of
    $n$. Print $n$, the sum and the error, which is now computed with \code{fabs(area - exact)},
    where \code{exact} is the answer you calculated. How does the error change when $n$ is
    multiplied by ten, compared with $\sin(x)$ in c)?
\end{parts}
