\chapter{Mathematics in C}
\label{c18:ch}

{\large\itshape The mathematics of the course written as programs: from hand calculation to code
that calculates the same way.\par}

\begin{chapterbox}{In this chapter}
\begin{itemize}
  \item The standard library \file{math.h}: functions, constants and linking with \code{-lm}.
  \item Floating-point numbers in C: \code{float} and \code{double}, and how they differ from the
    integer types you have already used.
  \item Powers, roots, logarithms and decibels in code.
  \item Trigonometric functions, and converting between degrees and radians.
  \item Numerical differentiation and integration.
  \item Complex numbers and phasors with \file{complex.h}.
  \item Sampling a sinusoidal signal -- from formula to sequence of numbers.
\end{itemize}
\end{chapterbox}

This chapter is a lab. It gathers the mathematics of the earlier chapters -- powers, logarithms
and decibels, trigonometry, derivatives, integrals and complex numbers -- and lets a computer do
the same calculations. Each exercise is solved in two steps: first by hand, then with a C program
that uses the standard libraries \file{math.h} and \file{complex.h}, after which the results are
compared. The code is written and run in the web browser, in the OnlineGDB compiler, so no
installation is needed. The chapter assumes basic C programming: variables, functions,
\code{printf()} and loops. Floating-point numbers are covered in the chapter.

\Secref{c18:sec:mathh} to \secref{c18:sec:fallgropar} are the theory: how each part of the
mathematics is written in C and what pitfalls there are, and \secref{c18:sec:typexempel} works
through five examples. \Secref{c18:sec:sammanfattning} summarises what you should be able to do,
and \secref{c18:sec:uppgifter} holds the lab's exercises. Parts~1--3 are compulsory, and Parts~4
and~5 are optional further study.

\begin{aside}
\note[Preparation] Read the theory and do the \textbf{hand calculations for all the exercises in
Parts~1--3} before the lesson. The lesson time is not enough for both calculating and
programming, and the calculations are required to pass. Also open
\url{https://www.onlinegdb.com/online_c_compiler}, check that the language is set to \textbf{C}
and press \textbf{Run}: the example program should print \code{Hello World}.
\end{aside}
