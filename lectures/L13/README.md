# L13 – Derivata (del II)

## Dagordning
* Derivatan för trigonometriska funktioner, exponentialfunktioner samt logaritmfunktioner.
* Genomgång av övningsdugga 2 (del II).
* Genomförande av **dugga 2**.

---

## Mål med lektionen
* Lära sig derivata för vanligt förekommande funktioner.
