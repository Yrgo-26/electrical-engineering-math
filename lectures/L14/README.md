## Demonstration
* Integrering av $f(x) = 2x + 1$ för att bestämma arean för $0 \leq x \leq 2$.
* Integrering av $f(x) = x^2$ för att bestämma arean för $0 \leq x \leq 3$.
* Integrering av $i(t) = 2t + 4$ för att bestämma laddningen $q(t)$ för $0 \leq t \leq 2$.

Laddningen $q(t)$ ges av

```math
q(t) = \int_0^t i(t)\,dt,
```

där $q(0) = 0$. Även bestämning av den primitiva funktionen $I(t)$ till $i(t)$ via givet startvillkor.
